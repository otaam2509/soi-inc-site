化粧品・健康食品の動画で気をつけたい表現｜効能を言い切らず「場面」で伝える

化粧品や健康食品の動画では、効能・効果の言い切りや、使用前後の比較、体験談の扱いに注意が必要です。表現で迷いやすい点と、場面で魅力を伝える考え方、台本段階での確認の進め方を解説します。

化粧品や健康食品の動画を作るとき、いちばん伝えたいのは「使うとどうなるか」です。ところが、その「どうなるか」の伝え方には、薬機法や景品表示法などの決まりがあり、言い方ひとつで受け取られ方が大きく変わります。

動画は、文章よりも印象が強く残ります。ナレーションやテロップ、映像の見せ方で、意図せず「効く」と言い切ったように受け取られてしまうこともあります。

この記事では、化粧品・健康食品の動画で迷いやすい表現と、効果を言い切らなくても魅力が伝わる「場面で見せる」考え方、台本の段階で確認しておきたいことを整理します。なお、ここで書くのは一般的な考え方であり、個々の表現が問題ないかどうかの判断は、御社の法務や専門家とのご確認をお願いします。

迷いやすい表現の種類

動画で注意したい表現は、大きく分けて次のようなものです。

  • 効能・効果の言い切り（「使えば必ず〇〇になる」のような受け取られ方をする言い方）
  • 使用前後の比較（ビフォーアフターの映像や画像）
  • 体験談（「私はこうなりました」という声）
  • 他の商品との比較や、「いちばん」「唯一」といった強い言い方

どれも商品の魅力を伝える自然な手段ですが、見る人がどう受け取るかによって、扱い方が変わります。

効能・効果を言い切らない

商品に認められている範囲を超えて、体や肌が「こう変わる」と言い切る表現は、避ける必要があります。化粧品と健康食品では、それぞれ言ってよい範囲が異なります。

ナレーションだけでなく、映像や字幕も同じ

言葉で言い切っていなくても、映像で「飲んだら一瞬で変わった」ように見せたり、字幕で強く印象づけたりすれば、同じ受け取られ方をすることがあります。セリフ、テロップ、映像の流れ、すべてで一貫して確認することが大切です。

使用前後の比較と体験談の扱い

使用前後を並べる見せ方や、体験談は、説得力がある分、慎重な扱いが求められます。

使用前後の比較

比べる条件がそろっているか、期間や使い方の説明が足りているか、写真や映像に加工が入っていないかなど、見る人が誤解しない状態になっているかが問われます。

体験談

「個人の感想です」と添えれば済む、という単純な話ではありません。体験談を通じて、効果が保証されているように見えないかという視点で確認します。

こうした点は、商品や広告の出し方によって判断が変わるため、動画に入れるかどうか自体を、御社の法務や専門家と相談して決めておくと安心です。

「場面」で魅力を伝える

効果を言い切れないとき、魅力を伝える方法がなくなるわけではありません。ショートドラマのように、使う人の暮らしの一場面を見せるやり方は、この点でとても相性がよい方法です。

効果ではなく、気持ちと暮らしを描く

たとえば、朝の支度の時間がいつもより少し楽しみになる。お風呂上がりのひとときに、ほっとする。夜のひと息に、自分をいたわる時間ができる。そんな使う場面での気持ちの動きを描けば、「肌がこうなる」「体がこうなる」と言わなくても、商品のある暮らしの魅力は伝わります。

  • 主人公は、商品ではなく、使う人
  • 描くのは、効果ではなく、使う場面とそのときの気持ち
  • 商品の説明は、最後のひとことにとどめる

見る人が「こんな時間を過ごしたい」と感じてくれれば、それが商品への関心になります。

SOIの考え方

私たちは、効果や金額のような、言い方で受け取られ方が大きく変わる内容は、映像の中で言い切らず、文章での説明も慎重に扱うことを基本にしています。そのうえで、商品の魅力は、使う人の暮らしの一場面で見せる方針です。

台本づくりで使える工夫

  • 「どうなるか」ではなく、「どんなときに使いたくなるか」を描く
  • 結果よりも、使っている最中の心地よさや、手に取るまでの気持ちを描く
  • 主人公のセリフは、感想よりも日常の何気ないひとことにする

こうして組み立てると、見る人に「使ってみたい」と思ってもらいやすくなり、表現の確認でも直しが少なく済みます。

台本の段階で、御社と表現を確認する

表現の確認は、動画ができあがってからでは、直しの負担が大きくなります。映像の撮り直しや作り直しが必要になるからです。確認は、台本の段階で行うのがもっとも効率的です。

確認の流れの例

  1. 商品について、使ってよい言葉と避けたい言葉を、御社から教えていただく
  2. その範囲で、台本の案を作る
  3. 台本の段階で、セリフ、テロップ、場面の見せ方を御社に見ていただく
  4. 必要に応じて、御社の法務や専門家にも確認していただく
  5. 確認が取れてから、映像の制作に進む

商品を一番よく知っているのは御社です。私たちが判断するのではなく、御社と一緒に、台本の段階で確かめながら進めることが、安心して公開できる動画への近道です。

SOIの考え方

台本ができた段階で、セリフ・テロップ・場面の構成を御社にご確認いただいてから、映像の制作に進みます。表現の最終的な判断は、御社の法務や専門家のご確認のうえで行うものと考えています。

迷ったときの考え方

表現に迷ったときは、次のような視点で見直すと整理しやすくなります。

  • この言い方を、見る人は「必ずそうなる」と受け取らないか
  • 映像や字幕が、言葉以上の印象を与えていないか
  • 商品の実際の使い方や、認められている範囲から離れていないか
  • 見る人が、後から「思っていたのと違う」と感じないか

ここで大切なのは、作り手の意図ではなく、見る人の受け取り方で考えることです。意図は伝わらなくても、映像の印象は残るからです。

まとめ

  • 化粧品・健康食品の動画では、効能・効果の言い切り、使用前後の比較、体験談の扱いに注意が必要
  • ナレーションだけでなく、映像、字幕、流れ全体で受け取られ方を確認する
  • 個々の表現が問題ないかの判断は、御社の法務や専門家と確認のうえで行う
  • 効果を言い切らなくても、使う人の暮らしの一場面と気持ちで、商品の魅力は伝えられる
  • 確認は、映像を作る前の台本の段階で、御社と一緒に行うのがもっとも安全で効率的
